# The Quintessential Quintuplets: Five Promises Made with Her — Unofficial English Translation

**Version 1.0** · Nintendo Switch (Japanese release) · Title ID `0100B77019F76000`

An unofficial, fan-made English translation of *Gotoubun no Hanayome: Kanojo to Kawasu Itsutsu no Yakusoku* (*The Quintessential Quintuplets: Five Promises Made with Her*), which has no official English release.

This is a fan project. It is **not affiliated with or endorsed by** MAGES., Spike Chunsoft, Kodansha, Negi Haruba or anyone else connected to the series. You need your own legally obtained copy of the game.

---

## Read this first: how it was translated

The script was **machine-translated** using custom scripts, then **reviewed and corrected by hand** during a complete playthrough of the game line by line.

## What is translated

- All story dialogue, character name tags, and choices
- System text (menus, save/load and confirmation messages), using the English that ships inside the game's own files with a few corrections
- Text drawn inside images (title and UI graphics) that are stored in the files included in this patch

## Known issues

- **9 images still show Japanese text.** They are simple images in the game's main image archive, which is not part of this patch (it is about 4.4 GB). Everything else is translated. Those 9 images are the images that show side of a character, anyone who played previous games would recall.

## Compatibility

- Works with the base game and with **update 1.0.1**, whether the update is enabled or not (tested both ways).
- Tested on **yuzu** but works on Ryujinx in the same way.

## Installation

Back up your save data before the first run.

### yuzu (and forks that use the same folders)

1. Right-click the game in the list and choose **Open Mod Data Location**, or open `<emulator data folder>\load\0100B77019F76000\` yourself.
2. Copy the `QQ-FivePromises-EN` folder into that folder, so you end up with `...\load\0100B77019F76000\QQ-FivePromises-EN\romfs\...`.
3. Right-click the game, open **Properties**, and make sure `QQ-FivePromises-EN` is ticked in the Add-Ons list.
4. Start the game.

### Nintendo Switch with custom firmware (Atmosphere)

Copy the `romfs` folder into `/atmosphere/contents/0100B77019F76000/` on your SD card, so you end up with `/atmosphere/contents/0100B77019F76000/romfs/...`.

### Uninstalling

Delete the `QQ-FivePromises-EN` folder (or the `romfs` folder on Atmosphere).
